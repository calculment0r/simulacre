# KUBERNÂN, OÙ SORTIR ? — Dossier de transfert

Ce dossier rassemble le livre #3 de la tétralogie, son architecture, le corpus, la méthode et le brief de mise en ligne. Point d'entrée pour reprendre le projet (Claude Code, ou plus tard).

## Ce que c'est
« Kubernân, où sortir ? » est le troisième livre d'une tétralogie. Il est la CARTE : il oriente. Forme rédigée, voix « nous » (Focus), registre Tiqqun froid. Voir `ARCHITECTURE_TETRALOGIE.md` pour le grand dessin.
